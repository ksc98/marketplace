# ksc98 marketplace

Claude Code plugins.

## Install

In Claude Code:

```
/plugin marketplace add ksc98/marketplace
/plugin install fantasy-draft@ksc98
```

Update later with `/plugin marketplace update ksc98`.

## Plugins

- **fantasy-draft**: a live pick advisor for Yahoo Fantasy Basketball 9-cat drafts. Open your Yahoo draft room in Chrome with [Claude in Chrome](https://claude.ai/chrome) connected, give Claude the draft URL, and say "up" when you're on the clock. It reads the board, tracks your roster's category balance and suggests the next pick. Extra NBA data comes from [nba-api.xyz](https://nba-api.xyz).
